# Gut Analysis Toolbox

Gut Analysis Toolbox (GAT) is a semi-automated toolkit for quantifying cells of
the enteric nervous system in 2D gut wholemounts. It runs in **Fiji** and
**QuPath** and uses deep-learning models to segment neurons, subtypes and
ganglia.

> **Migration in progress.** GAT v2 is a Fiji plugin (menu: **GATV2 › Start
> GAT**), replacing the old `.ijm` macros. These pages are being rewritten for
> v2 — some still describe the macro interface. Edit them in GitBook; changes
> sync back to the `docs/` folder of the repo.

## Editing these docs

This site is synced with a GitBook space. To edit, use the GitBook editor —
your changes are committed back to `docs/` as Markdown via a pull request, so
you do **not** need to touch code or use Git directly. New pages must be added
to `SUMMARY.md` to appear in the navigation.
