# Neuronal subtypes

Segment and count neuronal subtypes (nNOS, ChAT, Calbindin, Calretinin, MOR,
DOR, NFM) and express them as a proportion of total neurons.

**Outline**
- Assigning marker channels (with / without Hu)
- Running the subtype model
- Co-localisation with the Hu neuron count
- Outputs (per-subtype counts and proportions)
