# Model files

GAT ships three deep-learning models via the update site, installed into
`Fiji.app/models`.

**Models**
- **Enteric neuron** (StarDist) — segments Hu-labelled neurons.
  `2D_enteric_neuron_v4_1.zip`
- **Neuronal subtype** (StarDist) — segments subtype markers (nNOS, ChAT,
  Calbindin, Calretinin, MOR, DOR, NFM). `2D_enteric_neuron_subtype_v4_1.zip`
- **Ganglia** (DeepImageJ UNet) — segments ganglia from Hu + a neuronal/glial
  marker. `2D_Ganglia_RGB_v3`
