# Update sites & dependencies

GAT depends on several Fiji update sites. Enable them under **Help › Update… ›
Manage update sites**.

> **Stub — rewrite for v2.** Keep this list in sync with `README.md` and the
> `pom.xml` `app` profile (the authoritative dependency list).

**Required update sites**
- 3D ImageJ Suite
- BIG-EPFL
- CSBDeep
- clij
- clij2
- DeepImageJ
- Gut Analysis Toolbox — `https://sites.imagej.net/GutAnalysisToolbox/`
- IJPB-plugins (MorphoLibJ)
- StarDist
- PTBIOP

**Calcium imaging only:** add the unlisted **Template Matching** site manually
via *Add unlisted site*: `https://sites.imagej.net/Template_Matching/`
