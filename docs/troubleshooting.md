# Troubleshooting

Common problems and how the startup environment check (Preflight) helps.

> **Stub — rewrite for v2.** Reference: `UI/Preflight`.

**Outline**
- Reading the Preflight report at startup
- "Models missing" — check `Fiji.app/models` and the GAT update site
- Missing plugins — enable the required [update sites](getting-started/update-sites.md)
- Calcium imaging: Template Matching not installed
- DeepImageJ engines not initialised
